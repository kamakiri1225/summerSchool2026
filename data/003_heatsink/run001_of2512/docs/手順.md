# HeatSink マルチリージョン非定常解析 セットアップ手順

**ソルバ**: `chtMultiRegionFoam`（共役熱伝達、非定常）  
**OpenFOAM バージョン**: 2512  
**作業ディレクトリ**: `run001_of2512/`

---

## UNV メッシュのリージョン構成（実行結果確認済み）

| グループ名 | 種別 | セル数 | Z 範囲 (m) | OpenFOAM リージョン |
|---|---|---|---|---|
| `box` | セル体積（流体） | 91,319 | 0.002〜0.104 | fluid: `box` |
| `heatSink` | セル体積（固体） | 30,332 | 0.004〜0.023 | solid: `heatSink` |
| `heatSource` | セル体積（固体） | 4,155 | 0.002〜0.004 | solid: `heatSource` |
| `basis` | セル体積（固体・基板） | 23,659 | 0〜0.002 | solid: `basis` |
| `YMin` / `YMax` | 面グループ | — | — | inlet / outlet 境界 |
| `XMin` / `XMax` | 面グループ | — | — | 側面境界 |
| `ZMax` | 面グループ | — | — | 上面境界 |
| `Group_1` | 面グループ | — | — | `basis` 底面・外周境界 |

### リージョン間インターフェース

```
basis  ──[basis_to_heatSource]──  heatSource  ──[heatSource_to_heatSink]──  heatSink
  │                                    │                                         │
  └──[basis_to_box]── box ────[box_to_heatSource]  [box_to_heatSink] ──────────┘
```

> `basis`（Z=0〜2mm）は底面の基板プレート。ヒートソースとヒートシンクの下に位置し、
> 外周部は流体 `box` と直接接している。

---

## 手順概要

```
1. OpenFOAM 環境の有効化
2. chtMultiRegionFoam チュートリアルをコピー（ケース雛形）
3. ideasUnvToFoam でメッシュ変換
4. transformPoints で寸法スケール（mm → m）
5. splitMeshRegions でリージョン分割
6. 境界条件・物性値の設定（各リージョン）
```

---

## Step 1 — OpenFOAM 2512 環境の有効化

```bash
source /usr/lib/openfoam/openfoam2512/etc/bashrc
# または環境に合わせて
# source $HOME/OpenFOAM/OpenFOAM-v2512/etc/bashrc

# 確認
echo $WM_PROJECT_VERSION   # → 2512 が表示されること
```

---

## Step 2 — chtMultiRegionFoam チュートリアルをコピー

```bash
cd /path/to/run001_of2512

# multiRegionHeater チュートリアルを雛形としてコピー
cp -r $FOAM_TUTORIALS/heatTransfer/chtMultiRegionFoam/multiRegionHeater/system ./system
cp -r $FOAM_TUTORIALS/heatTransfer/chtMultiRegionFoam/multiRegionHeater/constant ./constant

# 0 ディレクトリは splitMeshRegions 後にリージョン別で作成するため、
# 雛形の 0 を参照用として保持しておく
cp -r $FOAM_TUTORIALS/heatTransfer/chtMultiRegionFoam/multiRegionHeater/0 ./0_ref
```

> チュートリアルのリージョン名（`topAir`, `heater` 等）は後で本ケース用に置換する。

---

## Step 3 — UNV → OpenFOAM メッシュ変換

```bash
cd /path/to/run001_of2512

ideasUnvToFoam Mesh_1.unv
```

変換後に生成されるファイル:

```
constant/
└── polyMesh/
    ├── points
    ├── faces
    ├── owner
    ├── neighbour
    ├── boundary
    └── sets/          ← UNV グループ → cellSets / faceSets
```

変換結果を確認:

```bash
# セルゾーン・フェイスゾーンが作成されているか確認
ls constant/polyMesh/sets/

# メッシュ情報を表示
checkMesh -allGeometry -allTopology 2>&1 | tee log.checkMesh
```

---

## Step 4 — 寸法スケール（mm → m、1/1000 倍）

UNV は mm 単位で作成されているため、OpenFOAM の SI 単位（m）に変換する。

```bash
transformPoints -scale '(0.001 0.001 0.001)'
```

スケール確認（変換後の境界ボックス）:

```bash
checkMesh 2>&1 | grep -A 3 "Overall domain"
# 期待値: X≈0.042 m, Y≈0.040 m, Z≈0.023 m
```

---

## Step 5 — splitMeshRegions でリージョン分割

セルゾーンをもとに流体・固体リージョンに分割する。

```bash
splitMeshRegions -cellZones -overwrite 2>&1 | tee log.splitMeshRegions
```

分割後のディレクトリ構成:

```
run001_of2512/
├── constant/
│   ├── box/polyMesh/          ← 流体リージョン
│   ├── heatSink/polyMesh/     ← 固体リージョン（フィン+ベース）
│   └── heatSource/polyMesh/   ← 固体リージョン（発熱体）
├── system/
│   ├── controlDict
│   ├── box/                   ← リージョン別 fvSchemes, fvSolution
│   ├── heatSink/
│   └── heatSource/
└── 0/
    ├── box/                   ← リージョン別初期・境界条件
    ├── heatSink/
    └── heatSource/
```

分割結果を確認:

```bash
checkMesh -region box       2>&1 | grep "cells:"
checkMesh -region heatSink  2>&1 | grep "cells:"
checkMesh -region heatSource 2>&1 | grep "cells:"
```

## Step 6 — 境界条件・物性値の設定（概要）

### 6-1. constant/regionProperties（設定済み）

```
regions
(
    fluid  ( box )
    solid  ( heatSink heatSource basis )
);
```

### 6-2. 各リージョンの物性値

| ファイル | リージョン | 設定内容 |
|---|---|---|
| `constant/box/thermophysicalProperties` | 流体 | 空気の熱物性 |
| `constant/box/turbulenceProperties` | 流体 | 乱流モデル（例: kEpsilon） |
| `constant/heatSink/thermophysicalProperties` | 固体 | アルミの熱物性 |
| `constant/heatSource/thermophysicalProperties` | 固体 | 発熱体の熱物性 |

**空気（box）の thermophysicalProperties 例:**

```
thermoType
{
    type            heRhoThermo;
    mixture         pureMixture;
    transport       const;
    thermo          hConst;
    equationOfState perfectGas;
    specie          specie;
    energy          sensibleEnthalpy;
}
mixture
{
    specie
    {
        molWeight   28.9;
    }
    thermodynamics
    {
        Cp          1005;
        Hf          0;
    }
    transport
    {
        mu          1.8e-05;
        Pr          0.713;
    }
}
```

**アルミ（heatSink）の thermophysicalProperties 例:**

```
thermoType
{
    type            heSolidThermo;
    mixture         pureMixture;
    transport       constIso;
    thermo          hConst;
    equationOfState rhoConst;
    specie          specie;
    energy          sensibleEnthalpy;
}
mixture
{
    specie
    {
        molWeight   26.98;
    }
    transport
    {
        kappa       205;    // 熱伝導率 [W/m·K]
    }
    thermodynamics
    {
        Cp          900;    // 比熱 [J/kg·K]
        Hf          0;
    }
    equationOfState
    {
        rho         2700;   // 密度 [kg/m³]
    }
}
```

### 6-3. 0/ 初期・境界条件（リージョン別）

`splitMeshRegions` 後に自動生成された `0/` 内のファイルを編集する。

| 境界 | T（温度） | U（速度） | 備考 |
|---|---|---|---|
| `YMin`（inlet） | fixedValue 300 K | fixedValue (0 0.5 0) | 流入温度・速度 |
| `YMax`（outlet） | inletOutlet | zeroGradient | 流出 |
| `XMin`/`XMax` | zeroGradient | slip | 側面 |
| `ZMax`（上面） | zeroGradient | slip | 上面開放 |
| `basis`（底面） | zeroGradient | noSlip | 底面壁 |
| `heatSource_to_heatSink` | 自動（共役） | — | 固体間界面 |
| `heatSource_to_box` | 自動（共役） | — | 固体-流体界面 |

### 6-4. heatSource の発熱量設定

```
// constant/heatSource/fvOptions
heatSource
{
    type            scalarSemiImplicitSource;
    active          true;
    selectionMode   all;
    volumeMode      specific;     // W/m³
    injectionRateSuSp
    {
        h  ( 1e7  0 );            // 発熱量を調整
    }
}
```

## Step 7 — 実行

```bash
# system/controlDict の設定確認（非定常: adjustableRunTime 等）
# endTime, deltaT, writeInterval を設定

# 並列分解（必要な場合）
decomposePar -allRegions 2>&1 | tee log.decomposePar

# ソルバ実行（逐次）
chtMultiRegionFoam 2>&1 | tee log.chtMultiRegionFoam

# または並列（例: 4 コア）
mpirun -np 4 chtMultiRegionFoam -parallel 2>&1 | tee log.chtMultiRegionFoam
```

## トラブルシューティング

| 症状 | 原因と対処 |
|---|---|
| `splitMeshRegions` で分割されない | UNV のセルゾーン（体積グループ）が正しく変換されていない → `ls constant/polyMesh/sets/` でゾーン確認 |
| スケール後のメッシュが巨大 or 極小 | `transformPoints` の前後に `checkMesh` で境界ボックス確認 |
| リージョン間の界面温度が不連続 | `regionProperties` の fluid/solid 定義が正しいか確認 |
| `checkMesh` で high aspect ratio 警告 | フィン間隙（3 mm）付近の細長セル → 許容範囲内なら無視可 |
