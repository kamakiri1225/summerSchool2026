## プロジェクト概要

OpenFOAM v2512 を使った撹拌機（スターラー）のメッシュ生成・変形ワークフロー。
ソースメッシュ（UNV形式）を読み込み、ゾーン定義・バッフル生成・動的メッシュ変形を行う。

## メッシュ生成ワークフロー

```bash
# 1. UNV メッシュをインポート
ideasUnvToFoam Mesh_1.unv

# 2. 座標変換（z軸周り-30°回転 → mm→m スケール変換）
transformPoints -rotate-angle '((0 0 1) -30)'
transformPoints -scale '(0.001 0.001 0.001)'

# 3. ゾーン定義
topoSet

# 4. バッフル壁面生成
createBaffles -overwrite

# 5. メッシュを master_curve にコピーして翼変形
cp -r case/constant/polyMesh master_curve/constant/
cd master_curve
moveDynamicMesh
```

## topoSetDict の構造

`topoSetDict` はエントリポイントのみで、実体は `#include` で分割：

```cpp
actions
(
    #include "topoSetDict.wing"   // wingFaceZone, wingFaceZone2
    #include "topoSetDict.circ"   // circularFaceZone_z015, circularFaceZone_z035
    #include "topoSetDict.rotor"  // rotor1, rotor2 (cellZone)
);
```

### フェイスゾーン選択のパターン

`planeToFace` は v2512 に存在しない。代わりに以下の組み合わせを使う：

```cpp
// 円柱内絞り込み
source  cylinderToFace;  p1/p2/radius

// z方向の薄層絞り込み（2枚のclipPlane）
source  clipPlaneToFace;  point / normal (0 0 1)   // 下限
source  clipPlaneToFace;  point / normal (0 0 -1)  // 上限

// 法線方向フィルタ（垂直面を除外）
source  normalToFace;  normal / cos
// cos は必ず -1〜1 の範囲。0.2 程度が湾曲翼には適切
```

### 法線方向の注意

同じメッシュでも z 高さによって内部フェイスの法線方向が逆になる：

| フェイスゾーン | normalToFace の normal |
|---|---|
| `circularFaceZone_z015` | `(0 0 1)` |
| `circularFaceZone_z035` | `(0 0 -1)` |

| 名前 | 種類 | 内容 |
|---|---|---|
| `wingFaceZone` | faceZone | z≈0.015 の翼面 |
| `wingFaceZone2` | faceZone | z≈0.035 の翼面 |
| `circularFaceZone_z015` | faceZone | z≈0.015 の円形ディスク（r≤15mm） |
| `circularFaceZone_z035` | faceZone | z≈0.035 の円形ディスク（r≤15mm） |
| `rotor1` | cellZone | 回転領域 r≤35mm, z=0.01〜0.02 |
| `rotor2` | cellZone | 回転領域 r≤35mm, z=0.03〜0.04 |

## master_curve（動的メッシュ変形）

- ソルバー: `moveDynamicMesh`
- モーションソルバー: `displacementSBRStress`
- 拡散係数: `quadratic inverseDistance ("wall_wing.*")`
- 翼変形: `pointDisplacement` の `codedFixedValue`（`makecurve`）
  - x=15〜25mm の範囲で y 方向に円弧状に変位
  - 時刻 t=1 で最終形状になるよう設計
  - `endTime 1; deltaT 0.1;`

## よくあるエラーと対処

| エラー | 原因 | 対処 |
|---|---|---|
| `Unknown topoSetSource type planeToFace` | v2512 に存在しない | `clipPlaneToFace` 2枚で代替 |
| `tolerance not within range -1..1 : N` | `normalToFace` の `cos` 値が範囲外 | `cos` を 0〜1 の範囲に修正 |
| `faceLabels List<label> 0()` | 指定 z にフェイスが存在しない | clipPlane 範囲を広げて確認、法線方向を反転して確認 |
| negative cell volume / high aspect ratio | バッフル生成または動的メッシュ変形でセルが反転 | `createBaffles` 前後の faceZone を確認 |
